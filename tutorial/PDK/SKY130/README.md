# SKY130 views for the FIFO example

These technology LEF, merged standard-cell LEF, and TT Liberty views were
restored from the earlier FIFO tutorial. The library is SKY130 FD SC HD at
1.8 V and 25 °C. Geometry uses the native scale, timing uses ns, and
capacitance uses pF.

The files retain their original notices. The [Apache 2.0 licence](LICENSE)
is included from the [SkyWater PDK repository](https://github.com/google/skywater-pdk).
